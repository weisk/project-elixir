# concept look & feel


These concepts are actually very usable for a premium CBD brand. The important thing is that they already establish:

* luxury
* ritualistic / mythological vibe
* premium black+gold identity
* feminine-organic elegance
* strong contrast

The danger now is:
if you inject “green CBD vibes” carelessly, you instantly downgrade the brand into:

* cheap cannabis shop
* neon weed culture
* vape-store aesthetics

So the key is:
green must become an *accent ecology layer*, not the primary identity.

The identity remains:
black + gold.

Green becomes:
life / botanical / premium-natural signalling.

Here are the palettes I would seriously consider.

# UI recommendations (VERY important)

## Use black properly

Do NOT use:

```txt id="1"
#000000 everywhere
```

Use layered darks:

* `#0A0A0A`
* `#121212`
* `#1A1A1A`

This creates depth.

---

## Gold usage

Gold should NEVER dominate large surfaces.

Use gold for:

* borders
* icons
* hover states
* separators
* headings
* logo
* premium highlights

Too much gold = casino website 😄

---

## Green usage

Green should communicate:

* plant origin
* calmness
* wellness

NOT:

* “WEED STORE”

Avoid:

* neon green
* bright lime
* saturated cannabis leaf aesthetics

---

# Typography direction

You absolutely want contrast between:

## Elegant serif

for headings

Examples:

* Cinzel
* Cormorant Garamond
* Playfair Display

and:

## Clean sans-serif

for UI/body

Examples:

* Inter
* Manrope
* Geist
* General Sans

That combo will massively elevate perceived quality.
